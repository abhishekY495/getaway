# Getaway

A mobile travel and experiences app. <br/>
Getaway lets users discover experiences, view event details, make bookings, manage their bookings, and interact with an AI concierge.

## Features

- User authentication with Clerk
- Browse and search experiences
- View and manage bookings
- AI Concierge for searching experiences and answering booking-related questions
- Push notifications

## Tech Stack

### Mobile

- React Native + Expo
- TypeScript
- NativeWind
- TanStack React Query
- React Hook Form
- Gorhom Bottom Sheet

### Backend

- Node.js
- Express
- TypeScript
- Drizzle ORM
- Neon PostgreSQL
- Clerk
- Zod

### AI

- Google Gemini API
